# Modelos de audio

Modelos de [Essentia](https://essentia.upf.edu/models.html) (Music Technology Group, Universitat Pompeu Fabra), en formato ONNX:

- `discogs-effnet-bsdynamic-1` — 400 estilos musicales de Discogs + embedding de 1280 dimensiones (huella para la radio).
- `mtg_jamendo_moodtheme-discogs-effnet-1` — 56 moods/temas a partir del embedding anterior.
